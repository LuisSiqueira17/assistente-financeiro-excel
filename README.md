# Assistente Financeiro para Excel

Pacote inicial do suplemento. Esta versão de teste verifica a conexão com o Excel e lista apenas nomes de tabelas e colunas; não envia dados financeiros para serviços externos.

## Arquivos
- `index.html`: painel do suplemento.
- `manifest.xml`: manifesto para carregar o suplemento no Excel.
- `icon-32.png` e `icon-64.png`: ícones.
